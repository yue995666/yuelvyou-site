# 悦旅游网站 · 项目说明

本仓库托管 `https://yuelvyou.cn` 的公开静态网页，**包含多个独立页面**，不能将《销售聚宝盆》的修改误应用到其他网页。

| 路径 | 用途 |
| --- | --- |
| `/` | 现有旅游网站首页 |
| `/dayueyue/` | 大悦悦个人介绍 |
| `/sales/` | **销售聚宝盆 · 公开体验版** |

## 销售聚宝盆

网站地址：<https://yuelvyou.cn/sales/>  
**详细产品说明、开发约束、测试和交付清单：[`sales/README.md`](sales/README.md)。**

> **隐私界限**：本仓库是公开仓库。禁止提交任何真实客户资料、微信聊天记录、个人销售复盘原文、未授权的老师课程原文、API 密钥或私有备份。分享公开界面 ≠ 分享个人客户信息。

## 必须遵守的开发约束

1. **每次完成一个逻辑改动，必须创建可追溯的 Git commit**，说明改动目的；不能只改线上文件不留提交。
2. **每次代码或功能改动，必须编写或更新相关测试**；文档/规则调整也要检查文档约束测试。
3. **交付前所有相关自动化测试与人工验收必须通过**；若失败，先修复；若受环境限制未验证，明确说明，不得声称全部通过。
4. **保护客户隐私和销售诚信**：公开版仅使用虚构示例；不能把规则回复描述成在线 AI，不能夸大收益或臆造客户成交。
5. **不得破坏其他站点**：修改 `/sales/` 时，不得无关地修改 `/`、`/dayueyue/` 或 `CNAME`。

从仓库根目录运行销售聚宝盆测试：

```bash
python -m pytest -q sales/tests
```

运行前需安装 `pytest`、`playwright`，并在本机配备 Chromium。详细安装说明、发布规范与回滚命令请看 [`sales/README.md`](sales/README.md)。
