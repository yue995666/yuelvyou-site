# 销售聚宝盆 · 公开体验网站

路径：`https://yuelvyou.cn/sales/`（GitHub Pages 生成并部署后可用）。

这是可以自行体验的静态网页，**不是带账号的线上 CRM**。示例客户均为虚构，新增/修改/聊天/任务记录只存储在**当前浏览器的 localStorage**，不上传服务器、不跨设备同步，清除浏览器数据可能丢失，请及时在「设置」导出备份。

AI 聊天助手当前基于**本地关键词规则**，不是真正的在线大模型，上传图片仅作本地预览，没有 OCR。

用户真实客户档案、个人销售复盘与老师的课程原文**禁止添加到本公开仓库**。公开网站的 UI 和代码可以公开分享，不代表可以公开分享个人客户数据。

## 验证方式

在 Python 环境安装 `pytest`、`playwright`，并安装 Chromium 浏览器。

```bash
python -m pytest -q sales/tests/test_public_site.py
```

测试包括：禁止真实客户混入、页面加载、搜索、创建客户、刷新后保存、拒绝推销保护、任务创建/完成、移动端导航、截图不触发上传。

## 将私人历史复盘导入公开应用（仅保存在自己的浏览器）

当前公开站点 `/sales/` **不会预置、托管或同步任何私人客户信息**。用户可以从「我的客户 → 合并导入历史档案」或「设置 → 合并导入历史客户档案」选择自己的 JSON 文件。支持只包含 `clients` 数组的历史复盘存档，不要求有 `tasks`。导入前需确认，同一「姓名 + 资料出处」的条目不会被重复导入；已有档案、用户手工编辑、跟进任务和设置均不会被覆盖。同名不同来源仍保留独立档案，避免误合并。

**重要限制：** 先前收集的209条历史档案是客户复盘条目（对应199个不同姓名或昵称），不是209份逐字微信聊天。未取得完整聊天导出或原始截图时，不得展示、推断或伪造聊天双方的原话；“复盘记载成交”也不能当作已核实398元收款。客户数据保存在各浏览器的 `localStorage` 中，清除站点数据或换设备会丢失/无法看到，请定期「导出全部客户与任务 JSON」备份。不要在共享电脑导入敏感资料，也不要将私人客户 JSON、聊天内容或收款证据提交到公开 GitHub 仓库。

## V5 实际交付与开通步骤

保留海景蓝白与温暖旅行风格、今日工作台、我的客户、聊天助手、跟进计划，增加手机底部导航和证据分级。游客无需注册，本地规则演示不消耗在线模型；截图仅本地预览，没有自动 OCR。A 明确购买表达、B 具体需求或询价、C 愿意了解、D 信息不足、E 明确拒绝或暂缓；仅匹配“客户：”或“对方：”行，其他行不作为客户原话。未知信息保持未知，注册游客与购买398元会员不混为一谈。每条建议需人工确认，不把报价或兴趣当付款。

当前仓库没有服务凭据，**尚未实现线上账号开通、真实 AI 调用和跨端同步的生产验证**。前端 `config.js` 默认空地址，登录禁用，必须明确披露未开通；不开假登录、不自动把失败的真实 AI 请求降级为规则。`backend/worker.mjs` 是可部署的安全接口实现，`backend/schema.sql` 是私有数据表、RLS 及原子版本检查。API 密钥只能放服务端。

1. 在自己的 Supabase 项目执行 `backend/schema.sql`（一次性迁移），启用邮箱密码认证、邮箱验证和安全密码策略；配置自己的邮件发送服务、注册邀请与密码找回流程。V5 前端先支持已有账号登录，未提供自助注册表单。不要公开注册无审核的试用账户；以两个测试用户验证隔离。
2. 在 Cloudflare 配置专用 Worker，使用 `backend/wrangler.toml`。通过 `wrangler secret put SUPABASE_URL`、`SUPABASE_ANON_KEY`、`OPENAI_API_KEY` 写入服务端环境；不要写入仓库或前端。Worker 使用用户 JWT 和 RLS，不使用绕过隔离的 service-role key。为模型项目设置费用上限。限流绑定缺失时接口拒绝服务。
3. `ALLOWED_ORIGIN` 设置为 `https://yuelvyou.cn`，绑定独立 HTTPS API 域名。先检查 `/health`，再用测试账号完成登录、分析、存储、退出、第二设备读取，以及两用户越权读写检查。日志不得记录密码、token、客户聊天；第三方服务可能处理文本，应明确取得客户资料处理授权并按需脱敏。
4. 完成真实服务验收后，把 `sales/config.js` 的 `SALES_API_BASE` 改为该 HTTPS API 地址，更新对应测试，全部通过才提交 Git commit 并发布。生产限流、费用、邮件和服务供应商在本次没有凭据时无法代开通。

私有空间在内存中维护，token 不持久化、账号资料不写入游客 localStorage；刷新需重登。编辑后使用「上传当前私有数据」持久化，其他设备登录读取；并非自动实时同步。版本冲突不覆盖，先导出本页，再下载云端并人工合并。退出前提示备份。游客资料迁移必须显式确认，先在游客空间导出备份，然后登录迁移；同姓名＋来源去重，保留云端手工修改。本机任务在游客备份中保留，不会隐式上传至账号。完整恢复仅游客空间可用，导入前自动留恢复点；设置可还原，失败不替换数据。请同时保留下载的 JSON，浏览器恢复点不能替代离线备份。

### 开发与回滚约束

每次变更更新对应测试，运行 `python -m pytest -q sales/tests`，相关检查全部通过才提交，报告 commit SHA、真实线上结果和手机验收。浏览器测试可通过 `SALES_CHROMIUM_PATH` 指定 Chrome，默认使用 Playwright 自带浏览器。API 单测用 `node --test sales/backend/worker.test.mjs`，覆盖鉴权、证据伪造、限流、账号隔离转发、冲突和错误处理；第三方真实端到端必须在开通后执行，不得以模拟测试冒充。

回退界面：`git revert <commit-sha>`，推送后验证 Pages。新版本未改旧浏览器 key `jbp_demo_v3_2026`，恢复本机数据从设置导入此前 JSON。数据库升级前由项目管理员做 Supabase 数据库备份；此迁移为新增独立表，不修改历史表。跨端冲突先离线备份，禁止强制覆盖。备份、209条个人复盘、199位客户档案、支付凭证、微信原文与老师的课程原文禁止提交公开仓库。
