# V5 交付边界

可用：公开游客入口、蓝白旅行风格、手机底部导航、客户卡片、粘贴聊天、本地截图预览、A–E规则建议和原文证据、人工确认存档、跟进任务、同来源去重导入、JSON备份与导入前恢复点。旧存储键沿用，不自动上传私人历史资料。拒绝后不因新询价自动解除保护。

服务端交付：独立 Worker 的 `/health`、`/login`、`/analyze`、`/state`；Supabase RLS 私有表和原子版本保存；服务端模型调用、逐条证据校验、身份验证、限流、来源限制、错误与冲突处理。前端已有连接逻辑和内存隔离账号空间，默认未连接。

未开通/未实测：真实 Supabase 认证、数据库 RLS 执行、Cloudflare Worker 部署、生产模型调用、真实跨端同步、邮件邀请/密码重置。无服务凭据，本次不得宣称上述已上线。前端默认禁用账号登录与真实 AI；没有 OCR 或自动实时同步。账号登录后需手动上传；刷新需重新登录。

开通操作见 README 的「V5 实际交付与开通步骤」。生产验收必须至少使用两个测试账号，分别创建私有客户，尝试不同用户的 JWT 和自造 user_id 读写，确认 RLS 拒绝；两设备制造相同 revision 写冲突，确认不覆盖。确认日志无私人聊天和凭据，并设模型服务费用上限。当前后端测试模拟第三方 HTTP，不能替代这些生产验证。

本机测试环境为独立 Python 虚拟环境、Playwright 和已有 Chrome。21项前端回归（含真实本地 HTTP 资源加载与刷新存储），8项后端模拟测试通过；手机宽390px与桌面1365px检查。测试仅使用虚构数据。CI会在后续销售模块变更时重跑。

没有读取、提交或上传用户209条私人复盘、199位客户资料、微信数据库、付款凭证或课程原文；原有私有资料仍留在用户原设备/浏览器，本次无法对未提供的数据文件做逐条迁移验收。
